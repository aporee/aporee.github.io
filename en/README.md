# English Version - KESA Website

This folder contains the English version of the KESA (Korea Electric Saving Association) website.

## Folder Structure

```
en/
├── index.html              # English main page
├── products/               # Product information pages
│   └── index.html         # Products overview
├── cases/                  # Case studies and examples
├── manufacturing/          # Manufacturing information
├── docs/                   # Documentation and resources
├── images/                 # Image assets
├── assets/                 # CSS and other assets
└── README.md              # This file
```

## Features

- **Bilingual Support**: Easy language switching between Korean and English
- **Responsive Design**: Mobile-friendly layout
- **SEO Optimized**: Proper meta tags and descriptions
- **Accessibility**: ARIA labels and semantic HTML

## Language Switching

Each English page includes a language switch button in the top-right corner that allows users to return to the Korean version.

## Content Translation

All content has been professionally translated from Korean to English while maintaining the technical accuracy and professional tone appropriate for international business communication.

## Navigation

The English version maintains the same navigation structure as the Korean version:
- About Us
- Products
- Effects & Features
- Case Studies
- Contact
